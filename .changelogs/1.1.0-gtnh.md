# Prehooked 1.1.0-gtnh

- Added configurable range, projectile speed, player pull speed, retract speed, and maximum anchor count for every
  hook tier while retaining existing defaults.
- Added authoritative server-to-client synchronization for `searchLocations`, Red Hook flight, and every per-tier
  statistic used by prediction/rendering, plus automatic local configuration restoration after disconnecting.
- Split retract speed from player pull speed and hardened configurable projectile movement, anchor limits, and
  long-range synchronization.
- Corrected Red Hook center movement to remove an occasional client-prediction snap while retaining authoritative
  collision and rope-range constraints.
- Added configuration, bounds, network round-trip, connection override, and disconnect recovery tests.

## Compatibility

- Minecraft 1.7.10 / Forge 10.13.4.1614
- GT New Horizons 2.9.0-beta-2 and 2.8.4
- Baubles Expanded is required

Install the same `prehooked-1.1.0-gtnh.jar` on both the client and dedicated server.
The release includes `SHA256SUMS.txt` covering every attached JAR.
