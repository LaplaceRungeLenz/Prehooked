# Prehooked 1.1.1-gtnh

- Fixed jump-retracting after a block or partial block stalls an unfinished pull: the release now discards the
  synthetic pull velocity and jumps straight up instead of launching forward.
- Lowered the stationary jump-retract apex from approximately 2 blocks to approximately 1.5 blocks while retaining
  momentum-scaled releases during unobstructed movement.
- Added regression tests for stalled-pull detection, momentum suppression, and release height.

## Compatibility

- Minecraft 1.7.10 / Forge 10.13.4.1614
- GT New Horizons 2.9.0-beta-2 and 2.8.4
- Baubles Expanded is required

Install the same `prehooked-1.1.1-gtnh.jar` on both the client and dedicated server.
The release includes `SHA256SUMS.txt` covering every attached JAR.
