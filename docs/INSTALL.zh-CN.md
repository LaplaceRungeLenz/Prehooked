# Prehooked 1.7.10 / GTNH 安装与使用

## 兼容范围

此版本的主要目标是 GT New Horizons `2.9.0-beta-2`，并回归兼容稳定版 `2.8.4`。它分别在整合包自带的
Baubles Expanded `2.2.21-GTNH` 和 `2.1.19-GTNH` 环境中验证过。模组只支持 Minecraft `1.7.10`；不要同时
安装原版 Hooked 的 1.12.2 JAR。

## 安装

1. 关闭客户端和服务端。
2. 将 `prehooked-1.0.3-gtnh.jar` 放入客户端实例的 `mods` 目录。
3. 多人游戏时，也把完全相同的 JAR 放入服务端的 `mods` 目录。
4. 确认整合包中存在 Baubles Expanded。GTNH 2.8.4 和 2.9.0-beta-2 已自带所需版本。
5. 启动游戏。首次启动会生成 `config/hooked.cfg`。

正式文件的 SHA-256 见分发包中的 `SHA256SUMS.txt`；该值会在最终构建后写入。

游戏模组列表、Gradle 项目及发布文件均使用名称 **Prehooked**。为兼容已经用 1.0.0-gtnh 创建或测试的世界，
内部 Forge 模组 ID、物品注册名、资源域和配置文件仍保留 `hooked`；这不是遗漏，也无需删除
`config/hooked.cfg`。

## 饰品栏

钩爪属于 Baubles Expanded 的通用饰品，可以放入可接受通用饰品的槽位。一个玩家同时只能装备一个钩爪；
第二个钩爪会被拒绝。默认情况下，功能只查找饰品栏里的钩爪。

## 操作

- `C`：发射钩爪，可在“选项 → 控制”中改键。
- 潜行 + `C`：收回准星附近的单根钩爪。
- 跳跃：收回全部钩爪并获得脱钩上抬速度；当前速度越大，释放后的跳跃越高，并保留增强后的水平动量。
- 潜行 + 右键多钩爪物品：切换“最多一个锚点”限制。
- 红石钩爪在至少一个锚点着陆后，可用 WASD、跳跃和潜行在绳长及锚点围成的区域内移动；快速双击跳跃可收回。

木、铁、钻石、红石、末影钩爪分别拥有 1、2、4、4、1 个锚点，最大距离分别为 8、16、24、24、64 格。
铁质钩头速度为每 tick 3.6 格，略低于原版约 3.92 格/tick 的终端下落速度；钻石钩头为每 tick 5.0 格，
高于该速度。末影钩爪近似瞬时抵达，并沿绳索显示末影粒子。

绳索使用两个线进行无序合成。发射后世界中的钩头使用与五种钩爪配色对应的四爪 3D 模型；这套模型材质与
物品栏中的钩爪图标相互独立。

## 配置

`config/hooked.cfg` 中的主要项目：

- `searchLocations`：查找位置位掩码，`1=饰品栏`、`2=手持`、`4=快捷栏`、`8=主物品栏`；可以相加。
  默认值为 `1`，优先顺序也按上述顺序。
- `stateSyncInterval`：活动钩爪状态包的间隔刻数，范围 1–20，默认 2；数值越低，其他玩家看到的绳索越平滑。
- `enableRedHookFlight`：是否允许红石钩爪的受限移动，默认 `true`。

多人游戏由服务端决定查找范围、红钩移动和锚点状态，建议客户端与服务端保持一致配置。

## 存档行为与排错

- 普通保存、退出和重新进入会保存已着陆的锚点。
- 死亡、跨维度、锚定方块消失，或玩家失去可用钩爪时会安全收回/清理状态。
- 若按键无反应，先确认钩爪确实在饰品栏，并检查是否有其他模组占用了 `C`。
- 若服务器提示缺少模组，确认客户端和服务端都安装同一个 Prehooked JAR，且未移除 Baubles Expanded。
- 分发包的兼容验证细节见 [VALIDATION.md](VALIDATION.md)。
